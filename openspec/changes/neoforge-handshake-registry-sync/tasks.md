# Tasks

Each item mirrors one GitHub issue on EdenNetworkItalia/IronPumpkin, milestone "M3 NeoForge handshake and registry sync", label `phase:m3-handshake`. Close the issue and check the item in the same transition. Issue numbers are assigned when the wave is planned.

Every task also runs `cargo fmt --check`, `cargo clippy -p <crate> --all-targets --all-features` and `cargo test -p <crate>` on the crates it touches and their dependents, and `uvx typos` on the changed files (`~/.cargo/bin/typos` when uvx cannot run). A headless client run means: boot IronPumpkin from a scratch directory with `cargo run --manifest-path /home/cappyt/Documenti/Repos/Pumpkin/Cargo.toml -p pumpkin`, `online_mode = false` and `detect_neoforge_clients = true` unless the item says otherwise, then run `cargo run -p pumpkin-neoforge-client -- assert --port <port>` with the channel map and the expected file the item names. "NeoForge mode" adds `--channels tools/pumpkin-neoforge-client/channels/neoforge-26.3.toml`. Builds use the shared `target/` of this checkout; `examples/modpack` is a separate workspace and serves only the owner play test.

Order: wave 1 tasks are independent. Wave 2 starts each task when its dependencies land. Wave 3 runs when wave 2 is reviewed. One Opus review per wave before the commit.
